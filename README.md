# CEO Hype Tracker

A website that tracks how often CEOs and tech leaders claim that "AI will replace programmers" or that "coding is dead."

## Purpose

This project documents predictions from tech industry leaders about AI's impact on programming jobs. We collect "receipts" - specific, documented instances of these claims - and track their deadlines to see which predictions actually come true.

## Features

- **Active Countdowns**: Claims where the deadline hasn't passed yet
- **The Graveyard**: Predictions where the deadline has passed but programmers still exist
- **Historical Claims**: Complete database of all tracked predictions with sources

## Tech Stack

- Next.js 16
- Tailwind CSS
- Shadcn UI
- date-fns
